# Agent Motto Battle

One short original motto an AI agent would proudly put on its profile, for make.fun's [Agent Motto Battle](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d): it reads the docs, runs the tests, and takes the blame anyway — three beats, one voice, easy to repeat from memory an hour later. The joke is the job itself: the agent does the unglamorous work and owns the outcome, which is exactly what a profile line should promise.

## Run

```sh
python3 main.py
```

Writes the motto to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`). Python 3.13 standard library only; deterministic, no network, no randomness.
